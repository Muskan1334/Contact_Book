# Contact Book
A menu-driven contact management application built using Python and JSON.

## Features
- Add new contact
- Store multiple phone numbers for a contact
- Delete a contact
- Delete a particular contact number
- Delete the entire contact book
- Search contact name
- Display all the contacts
- Edit a previous contact number
- Handle invalid numeric input using exception handling

## Technology Used
- Python

## How It Works
The application provides a menu through which users can manage their contacts. Each contact is stored with a list of contact numbers. The contact data is stored in a JSON file so that the information is available when the program is run again.
